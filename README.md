# 🍎 Fruit Image Classification using Deep Learning

This project focuses on building an automated fruit image classification system using deep learning techniques. The model is trained to identify and classify different types of fruits based on visual features such as colour, shape, and texture.

---

## 🚀 Project Overview

- Built using Convolutional Neural Networks (CNN) and transfer learning
- Classifies multiple fruit categories from images
- Achieves ~91–92% accuracy on test dataset
- Uses preprocessing, augmentation, and evaluation techniques for better performance

---

## 📊 Features

- Image preprocessing (resizing & normalization)
- Data augmentation (rotation, flipping, zooming, shifting)
- Deep learning model for feature extraction
- Multi-class classification using Softmax
- Performance evaluation using:
  - Accuracy
  - Confusion Matrix
  - Precision, Recall, F1-score
  - ROC Curve

---

## 🧠 Model Details

- Input: RGB fruit images
- Output: Fruit category prediction
- Loss Function: Categorical Crossentropy
- Optimizer: Adam
- Techniques used:
  - Batch Normalization
  - Dropout (to reduce overfitting)

---

## 📁 Dataset

- Dataset: Fruits 360 Dataset (Kaggle)
- Size: ~6GB
- Link: https://www.kaggle.com/datasets/moltean/fruits
